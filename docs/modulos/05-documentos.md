# Documentos, prompts y producción

**Requisitos.** Pestañas para leer/editar Markdown, guiones y notas; edición exacta por usuario y agente; varias vistas y división vertical/horizontal; ruta/breadcrumb; previsualización; seleccionar y enviar fragmento o archivo al compositor; rol prompt/contexto explícito; consultar producción y reutilizar prompts sin copiar manualmente entre programas. Formato de guion/imprimible puede ser una extensión futura, conservando convenciones del proyecto de escritura.

**Relación con otros proyectos.** Compartir carpeta y contrato acordado para proyectos, episodios, escenas, tomas, personajes, prompts y medios. No abrir ni alterar el proyecto editorial para inferir un formato ahora. Un archivo creado fuera puede indexarse; la procedencia ausente se marca como desconocida. Cuando se conecte, comprobar revisión/hash antes de sobrescribir para evitar perder ediciones de otro programa.

**Sugerencias.** Detectar menciones de recursos en un prompt, resolver IDs/canónicos/variantes y mostrarlos para revisar. En operaciones caras, respetar la política acordada contigo. Un archivo adjunto no se trata automáticamente como instrucciones de la generación.

**Entrega 1.** Borrador de texto exacto en navegador, revisión y dos vistas sincronizadas. No guarda todavía un archivo `.md` en una carpeta del sistema ni ejecuta Markdown/HTML. Vista previa y visor ampliado se añaden con el módulo real.

**Retos.** Distinguir borrador y archivo; conservación de etiquetas, sintaxis y referencias; conflicto con un agente/editor externo; exportación para guion sin alterar la sustancia.
